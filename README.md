## 🏗️ System Design Snapshots

**HireFlow: request flow**

```mermaid
flowchart LR
    U[👤 React Client] -->|HTTPS / JSON| API[Express REST API]
    API --> MW{Auth Middleware<br/>JWT + Role Check}
    MW -->|Job Seeker| S[Search, Apply, Save Jobs]
    MW -->|Recruiter| R[Post Jobs, Review Applicants]
    S --> DB[(MongoDB)]
    R --> DB
```

**MindBridge: RAG pipeline**

```mermaid
flowchart LR
    A[👤 User Message] --> B[😊 VADER Emotion Detection]
    A --> C[🔎 MiniLM Embedding]
    C --> D[(FAISS Vector Store)]
    D -->|Top-k context| E[🧩 Prompt Builder]
    B --> E
    E --> S{🛡️ Safety Filter}
    S --> F[⚡ Groq LLM]
    F --> G[💬 Response]
```
