## 🏗️ System Design Snapshots

### Hireflow: Request Flow (MERN)

```mermaid
flowchart LR
    U[👤 Client: React] -->|HTTPS / JSON| API[Express REST API]
    API --> MW{Auth Middleware<br/>JWT + Role Check}
    MW -->|Seeker| S[Apply / Save Jobs]
    MW -->|Recruiter| R[Post Jobs / Review Applicants]
    S --> DB[(MongoDB)]
    R --> DB
    S --> F[📄 Resume Storage]
```

### MindBridge: RAG Pipeline

```mermaid
flowchart LR
    A[👤 User Message] --> B[😊 Emotion Detection]
    A --> C[🔎 Embedding]
    C --> D[(FAISS Vector Store)]
    D -->|Top-k context| E[🧩 Prompt Builder]
    B -->|Emotion signal| E
    E --> F[⚡ Groq LLM]
    F --> G[💬 Response]
```
