## 🏗️ How MindBridge Works (RAG Architecture)

```mermaid
flowchart LR
    A[👤 User Message] --> B[😊 Emotion Detection]
    A --> C[🔎 Embedding]
    C --> D[(FAISS Vector Store)]
    D -->|Top-k context| E[🧩 Prompt Builder]
    B -->|Emotion signal| E
    E --> F[⚡ Groq LLM]
    F --> G[💬 Empathetic Response]
```

## 🛰️ Segmentation Pipeline (Ottermap Challenge)

```mermaid
flowchart LR
    A[🛰️ Aerial Imagery] --> B[Preprocessing & Tiling]
    B --> C[U-Net Model]
    C --> D[Binary Mask: Turf / Grass]
    D --> E[Polygonization]
    E --> F[🗺️ GeoJSON Output]
```
